# Ses10 Android

Ses10'un native Android istemcisi için Kotlin ve Jetpack Compose tabanlı başlangıç projesidir.
Bu aşamada ekranlar yalnızca yerel arayüz iskeletidir; backend, LiveKit, kimlik doğrulama ve
veritabanı bağlantısı içermez.

## Gereksinimler

- Android Studio (güncel kararlı sürüm)
- JDK 17
- Android SDK 35

Projeyi Android Studio'da bu klasörü seçerek açın. Gradle senkronizasyonundan sonra debug APK'yı
`Build > Build APK(s)` ile üretebilirsiniz.
